## Introdução

Este repositório apresenta a modelagem de um banco de dados para uma Clínica Veterinária.
O projeto passa pelas três etapas principais da modelagem de dados: modelo conceitual (DER),
modelo lógico (esquema relacional) e modelo físico (script SQL).

Nesta versão foram mantidas as mesmas entidades principais do projeto-base, com pequenas
adaptações nos atributos para detalhar melhor o cadastro de clientes, animais e veterinários.

## Arquivos

- `1_modelo_conceitual.png` - Diagrama Entidade-Relacionamento (DER)
- `2_esquema_relacional.txt` - Esquema relacional com PKs e FKs
- `3_dicionario_dados.pdf` - Dicionário de dados
- `4_script_fisico.sql` - Script DDL para MySQL Workbench

## Observações

O modelo utiliza as entidades Cliente, Animal, Veterinario e Consulta.
Os relacionamentos principais continuam sendo do tipo 1:N.
